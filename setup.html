🔑 Claves de Firebase

Obtén estos datos de Firebase Console → Configuración del Proyecto → SDK de administración

apiKey de tu configuración de Firebase

ej: mitienda.firebaseapp.com

projectId sin guiones ni espacios

ej: mitienda.appspot.com

🏪 Datos de tu Tienda

Información que verán tus clientes en la página y en los recibos

URL directa a imagen PNG o JPG (mejor GitHub o Imgur)

Color para botones y acentos

Los datos se guardan de forma segura en tu navegador.
Puedes cambiarlos después en Configuración → Restablecer
